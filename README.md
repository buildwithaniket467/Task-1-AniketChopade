# Decode Labs – Project 1

## Responsive Website

### Description
This project is developed as part of the Decode Labs Project 1 assignment. It is a responsive website built using HTML, CSS, and JavaScript, with a clean layout and a user-friendly interface.

### Features
- Responsive navigation bar
- Hero section
- Services section
- About section
- Contact form with basic validation
- Mobile-friendly design
- Dynamic copyright year
- Responsive layout for desktop, tablet, and mobile devices

### Technologies Used
- HTML5
- CSS3
- JavaScript

### Project Structure
```text
Project-1/
├── index.html
├── style.css
├── script.js
└── README.md
```

### How to Run
1. Clone or download the repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a browser or use the Live Server extension.
4. Test the website on different screen sizes.

### Note
The contact form includes frontend validation and a demo success message. It does not send data to a backend server.
